이 폴더에 배경음악 mp3 파일을 넣으세요.

사용 방법
1. 여기(music 폴더)에 mp3 파일을 넣습니다. (예: bgm.mp3, romantic.mp3)
2. 변경 사항을 배포(git push → Vercel 배포)합니다.
3. photo.html 관리자 페이지 → "🎵 배경음악 관리" 카드에서
   - "청첩장에서 배경음악 켜기" 체크
   - 재생할 곡을 목록에서 선택 (또는 파일명 직접 입력)
   - "저장"
4. 청첩장 화면 우측 하단의 🎵 버튼으로 하객도 직접 끄고 켤 수 있습니다.

참고
- mp3 파일 자체는 이 폴더의 정적 파일로 서비스되고(빠름),
  KV에는 "어떤 파일을 틀지 파일명 + on/off"만 저장됩니다(가벼움).
- 이미 넣어둔 곡들 사이 전환은 photo.html에서 즉시 되지만,
  '새 곡 추가'는 파일을 이 폴더에 넣고 다시 배포해야 반영됩니다.
- 모바일 브라우저는 소리 자동재생을 막기 때문에, 하객이 화면을
  처음 탭하거나 우측 하단 버튼을 누를 때 재생이 시작됩니다.
