$ARGUMENTS 파일을 영어로 번역해주세요.

## 번역 규칙

1. **기술 용어는 그대로 유지**: 변수명, 함수명, 컴포넌트명, CSS 클래스명, HTML 태그, CLI 커맨드, API 용어 등은 번역하지 않고 원문 그대로 둡니다.
2. **자연스러운 영어 표현**: 직역이 아닌, 원어민이 실제로 쓰는 자연스러운 표현으로 작성합니다.
3. **문서 구조 유지**: 헤더, 리스트, 코드 블록, 표 등 원본 마크다운 형식을 그대로 유지합니다.
4. **코드 블록 내용 번역 금지**: 코드 블록(``` ```) 안의 코드는 번역하지 않습니다. 단, 코드 블록 안의 주석은 영어로 번역합니다.

## 출력 형식

- 원본 파일과 **동일한 파일 구조**로 번역 결과를 출력합니다.
- 번역이 완료되면 원본 파일과 **같은 위치**에 동일한 파일명으로 저장합니다.
- 저장 전에 번역된 내용을 먼저 보여주고, 저장 여부를 사용자에게 확인합니다.
